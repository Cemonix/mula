# Mula

A dual-pane terminal file manager, inspired by [yazi](https://github.com/sxyazi/yazi) and Total Commander, with built-in support for managing files on remote servers via `rsync`/`scp`.

## Requirements

File icons are drawn from Unicode's private use area and need a [Nerd Font](https://www.nerdfonts.com/) installed in your terminal — without one they show up as empty boxes. Install the **Mono** variant specifically: other variants draw the glyph wider than one cell and it overflows into the next column.
